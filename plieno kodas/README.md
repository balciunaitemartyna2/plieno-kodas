# MB Plieno kodas

Statinis tinklalapis, paruoštas Vercel deploy.

## Deploy į Vercel

1. Prisijunk prie https://vercel.com
2. Sukurk naują projektą.
3. Įkelk šį aplanką per GitHub arba Vercel CLI.
4. Framework pasirinkimas: `Other`.
5. Build command: palik tuščią.
6. Output directory: palik tuščią arba `.`

Supabase šiam peržiūros tinklalapiui nereikalingas, nes nėra duomenų bazės ar backend funkcijų.
